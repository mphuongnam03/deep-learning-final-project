# TB AI React Frontend

## Install

```powershell
npm install
```

## Run

```powershell
npm run dev
```

Default URL: `http://localhost:5173`

Set a custom backend URL with:

```powershell
$env:VITE_API_URL="http://localhost:8000/api"
npm run dev
```

The app includes login/register, protected diagnosis upload, prediction history, dataset analytics, and training metrics dashboards.
